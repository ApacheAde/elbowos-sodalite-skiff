# Sodalite Skiff

Full-colour Python 3 neon canal-hopper arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a lime skiff up a violet canal. Hop banks. Ride teal ferries. Grab cyan pearls. Pink wrecks dump you back to the dock.

W / S hop lanes. A / D drift. R reset.

## Play

```
pip install -r requirements.txt
python3 sodalite_skiff.py --play
```

## Record a 9:16 reel

```
python3 sodalite_skiff.py --record
```

Writes `SODALITE_SKIFF_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
